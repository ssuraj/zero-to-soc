# Zero to SOC

A Budget-Friendly Roadmap to Your First Cyber Security Job.

**Author:** Suraj Wagh  
**Edition:** First Edition, 2026

## About

*Zero to SOC* is a beginner-friendly roadmap for starting a cybersecurity career, with a practical focus on SOC Analyst skills.

## Book

[Download / read the PDF](./Zero_to_SOC_Book.pdf)

## Topics covered

- Cybersecurity fundamentals and SOC concepts
- Networking, Windows and Linux fundamentals
- Logs, SIEM, triage and incident response
- Phishing, threat intelligence, MITRE ATT&CK and Wireshark
- Home labs and CTF practice
- Investigation reports and practical exercises
- A 16-week study plan
- Certifications, resume, LinkedIn, interviews and job hunting
- First 90 days and cybersecurity career paths
- Cheat sheets, checklists, resources, quiz answers, glossary and index
